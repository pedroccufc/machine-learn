# Shared Coursework Data

The datasets are stored beside the coursework notebooks in `coursework/data/` and referenced from `coursework/notebooks/` using `../data/<filename>`.

| File | Context |
| --- | --- |
| `adult.data`, `adult.names` | Adult / Census Income dataset and field notes |
| `iris.data` | Iris dataset |
| `wdbc.data` | Wisconsin diagnostic breast cancer dataset |
| `movie_data.csv` | Large movie-related CSV (approximately 65.9 MB) |
| `data_1024.csv` | CSV used in an exercise; inspect notebook for meaning |

Files are preserved unchanged. Their origins and licenses should be checked before redistribution or reuse. They were not newly generated by the refactor.
