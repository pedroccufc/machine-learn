# Datasets and supporting files

This directory holds datasets and reference files used across historical academic notebooks.

| File | Notes |
| :--- | :--- |
| `adult.data` / `adult.names` | Adult dataset and accompanying field description |
| `iris.data` | Iris flower dataset |
| `wdbc.data` | Wisconsin Diagnostic Breast Cancer dataset |
| `data_1024.csv` | CSV data used in studies; refer to the notebooks for context |
| `movie_data.csv` | Large movie-related CSV (~65.9 MB) |
| `placa-nova-mercosul-tudo-sobre.mp4` | Video asset (~14.2 MB); its relationship to the notebooks has not been verified |

## Data handling

- These datasets and media files are retained to preserve the academic work and its paths.
- Before redistributing, deploying, or reusing them commercially, verify their original sources and licenses.
- Avoid moving or renaming data files until all notebook references have been reviewed.
- New large binary artifacts should be kept out of routine Git commits where possible.
