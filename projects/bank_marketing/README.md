# Bank Marketing — Academic Project

Historical university experiments using a bank marketing dataset. The numbered notebooks reflect their original evolution rather than a verified production pipeline.

## Structure

```text
bank_marketing/
├── notebooks/
│   ├── 01_exploration.ipynb
│   ├── 02_iteration.ipynb
│   ├── 03_iteration.ipynb
│   └── 04_final.ipynb
├── data/
│   └── bank_marketing.csv
└── README.md
```

The source file was originally named `bank-additional-full.csv`. Its contents were moved unchanged to `data/bank_marketing.csv`; the notebook paths were updated accordingly.

## Usage

Start Jupyter from `notebooks/` so references such as `../data/bank_marketing.csv` resolve. Install the historical notebook's dependencies in an isolated environment before execution.

No model metric, competition score, or successful current execution is claimed.
